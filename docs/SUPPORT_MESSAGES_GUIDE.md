# 📩 دليل مسار رسائل الدعم الفني وإشعار الاستاف (`SUPPORT_MESSAGES_GUIDE.md`)

> **مخصص لمطوري الفرونت إند (Flutter & Web) وفريق الدعم:**  
> هذا المسار يتيح للمرضى والأطباء والممرضين إرسال رسائل واستفسارات الدعم الفني، ويقوم النظام فوراً وبشكل تلقائي بإنشاء إشعارات في قاعدة البيانات وإرسال إشعارات لحظية (Push Notifications عبر FCM) لجميع حسابات فريق الدعم الفني والإدارة (`Staff` و `Admin`).

---

## 🌐 تفاصيل الـ Endpoint:

* **المسار وطريقة الطلب (Method & Paths):**
  * `POST /api/support/message`
  * أو `POST /api/notifications/support-message` (مسار بديل مطابق)
* **الصلاحية المطلوبة (Auth):** `Bearer <accessToken>` لأي مستخدم مسجل (`Patient` أو `Doctor` أو `Nurse`).
* **Headers:**
  ```http
  Content-Type: application/json
  Authorization: Bearer <accessToken>
  ```

---

## 📥 جسم الطلب (Request Body):

| الحقل | النوع | الإلزامية | الوصف |
|---|---|---|---|
| `message` | String | **إجباري** | نص رسالة الدعم الفني أو المشكلة أو الاستفسار |
| `subject` | String | *اختياري* | عنوان أو موضوع المشكلة (مثل: "استفسار حجز"، "مشكلة في الدفع") |
| `bookingNumber` | Number / String | *اختياري* | رقم الحجز التسلسلي إن كانت الرسالة مرتبطة بحجز معين |

### مثال الطلب (Request Example):
```json
{
  "subject": "استفسار حجز",
  "message": "عندي مشكلة بخصوص الحجز رقم 1002، المريض يرغب في تغيير الموعد.",
  "bookingNumber": 1002
}
```

---

## 📤 الاستجابة الناجحة (Response 200 OK):

```json
{
  "success": true,
  "message": "تم إرسال رسالتك لفريق الدعم بنجاح وسيتم التواصل معك في أقرب وقت.",
  "data": {
    "senderRole": "Doctor",
    "senderName": "دكتور حازم",
    "message": "عندي مشكلة بخصوص الحجز رقم 1002، المريض يرغب في تغيير الموعد.",
    "notifiedStaffCount": 3
  }
}
```

## 🔔 ماذا يحدث في الخلفية عند استدعاء هذا المسار؟

1. **التعرف التلقائي على هوية المرسل:**
   يستخرج النظام بيانات المرسل من التوكن (الاسم، الدور، الهاتف، المعرّف).
2. **إنشاء إشعارات مخصصة لجميع حسابات الاستاف والأدمن:**
   * عنوان الإشعار: `📩 رسالة دعم فني جديدة من [طبيب/ممرض/مريض]: [اسم المرسل]`
   * نص الإشعار: `[الموضوع] نص الرسالة`
   * نوع الإشعار: `type: "support_message"`
   * البيانات المرفقة: معرّف المرسل، هاتفه، رقم الحجز، ونص الرسالة.
3. **إرسال Firebase Cloud Messaging (FCM Push):**
   يقوم السيرفر فوراً بإرسال Push Notification إلى هواتف ومتصفحات موظفي الدعم النشطين الذين قاموا بتسجيل أجهزتهم.
