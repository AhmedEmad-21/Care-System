
### 🩺 أولاً: فلترة الأطباء (`/api/doctors/filter`)

تُستخدم في حال أراد المستخدم الفلترة **بدون كتابة اسم**:
تقدر تبعت أي تجميعة (Combination) براحتك كـ Query Parameters:

* **التخصص فقط:**
`?specialization=باطنة`
* **التاريخ فقط:**
`?date=2026-09-10`
* **الموقع فقط:**
`?lat=29.3&long=30.8`
* **التخصص + التاريخ:**
`?specialization=باطنة&date=2026-09-10`
* **التخصص + الموقع:**
`?specialization=باطنة&lat=29.3&long=30.8`
* **التاريخ + الموقع:**
`?date=2026-09-10&lat=29.3&long=30.8`
* **التلت فلاتر مع بعض (التخصص + التاريخ + الموقع):**
`?specialization=باطنة&date=2026-09-10&lat=29.3&long=30.8`

> 🔍 **في حال وجود "اسم" مع الفلاتر (للأطباء):**
> يتم استخدام الـ Endpoint الخاصة بالبحث بالاسم، والتي تقبل الاسم ومع أي تجميعة من الفلاتر السابقة في نفس الوقت:
> 
> 
> * **`GET /api/doctors/search-by-name`**
> 
> * *مثال:* `?name=أحمد&specialization=باطنة&date=2026-09-10&lat=29.3&long=30.8`
> 
> 
>

### 💉 ثانياً: فلترة الممرضين (`/api/nurses/filter`)

تُستخدم في حال أراد المستخدم الفلترة **بدون كتابة اسم** (نظراً لعدم وجود تخصص):
تقدر تستخدم الفلترين أو كل واحد منفرد:

* **التاريخ فقط:**
`?date=2026-09-10`
* **الموقع فقط:**
`?lat=29.3&long=30.8`
* **التاريخ + الموقع (معاً):**
`?date=2026-09-10&lat=29.3&long=30.8`

> 🔍 **في حال وجود "اسم" مع الفلاتر (للممرضين):**
> يتم استخدام الـ Endpoint الخاصة بالبحث بالاسم، والتي تقبل الاسم مع فلاتر التاريخ والموقع معاً:
> 
> 
> * **`GET /api/nurses/search-by-name`**
> 
> * *مثال:* `?name=فاطمة&date=2026-09-10&lat=29.3&long=30.8`
> 
> 
>
